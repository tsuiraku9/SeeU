# Security policy

## Supported versions

Only the latest commit on `main` receives security fixes. This project is
pre-release software and does not currently maintain supported release branches.

## Reporting a vulnerability

Use the repository's
[private vulnerability reporting form](https://github.com/tsuiraku9/SeeU/security/advisories/new).
Do not disclose the issue in a public issue, discussion, pull request, log, or
fixture.

Never include platform passwords, Cookies, login tokens, session secrets, QR
codes, SMS codes, browser profiles, signed media URLs, private content, or
archived user data. Redact sensitive values and use synthetic examples wherever
possible.

If private vulnerability reporting is temporarily unavailable, open a minimal
public issue asking the repository owner to establish a private contact channel.
Do not include vulnerability details in that issue.

The maintainer will acknowledge a private report when practical, investigate
it, and coordinate disclosure after a fix is available. No response-time or
bounty commitment is currently offered.
